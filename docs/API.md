## Node kinds

A node's `kind` selects the schema its properties are validated against. Unknown
properties are a hard error (`DIM0301`), so a kind must register before its
scenes will load — which is also what makes the "did you mean" suggestion
possible.

Properties equal to their default are omitted from the file and filled in on
load, so a scene does not grow every time a kind gains a property.

### `AnimatedSprite2D`

A sprite playing frame clips imported from Aseprite tags.

| Property | Type | Default | Notes |
|---|---|---|---|
| `frames` | `asset-ref` | **required** | Imported sprite sheet carrying the named clips. |
| `animation` | `string` | `""` | Clip to play. Empty means the first. |
| `playing` | `bool` | `true` | Advance frames on tick. |
| `looping` | `bool` | `true` | Restart at the end of the clip. |
| `modulate` | `color` | `"#ffffffff"` | Tint. |
| `speed_numerator` | `int` | `1` | Playback rate numerator. Integer ratio, not a float, because frame advance is gameplay and must land on the same tick everywhere. |
| `speed_denominator` | `int` | `1` | Playback rate denominator. |
| `blend` | `enum(Alpha | Additive | Multiply)` | `"Alpha"` | Blend mode. |

### `Area`

A trigger volume. Reports overlaps and blocks nothing.

| Property | Type | Default | Notes |
|---|---|---|---|
| `shape` | `enum(AABB | Circle | Polygon)` | `"AABB"` | Which of the size, radius or points properties applies. |
| `size` | `vec2` | `[16.0, 16.0]` | Full extents, for an AABB. |
| `radius` | `scalar` | `8.0` | Radius, for a circle. |
| `points` | `list<vec2>` | `[]` | Convex hull in local space, counter-clockwise, for a polygon. |
| `collision_layer` | `int` | `1` | Bitmask of layers this body occupies. |
| `collision_mask` | `int` | `1` | Bitmask of layers this body tests against. |
| `monitoring` | `bool` | `true` | Report overlaps. A disabled area costs nothing in the broadphase. |

### `Camera2D`

A view onto the world.

| Property | Type | Default | Notes |
|---|---|---|---|
| `projection` | `enum(TopDown | Isometric)` | `"TopDown"` | Top-down is identity; isometric is a 2:1 shear applied at render time. The simulation is free-form 2D either way — this flag never reaches it. |
| `zoom` | `scalar` | `1.0` | Scale factor. |
| `current` | `bool` | `false` | Use this camera for rendering. |
| `pixel_snap` | `bool` | `true` | Round the camera to whole pixels, for pixel-art projects. |
| `limits` | `rect` | — | Region the view is confined to. Unconstrained when absent. |

### `Collider`

A solid body. Blocks movement and reports contacts.

| Property | Type | Default | Notes |
|---|---|---|---|
| `shape` | `enum(AABB | Circle | Polygon)` | `"AABB"` | Which of the size, radius or points properties applies. |
| `size` | `vec2` | `[16.0, 16.0]` | Full extents, for an AABB. |
| `radius` | `scalar` | `8.0` | Radius, for a circle. |
| `points` | `list<vec2>` | `[]` | Convex hull in local space, counter-clockwise, for a polygon. |
| `collision_layer` | `int` | `1` | Bitmask of layers this body occupies. |
| `collision_mask` | `int` | `1` | Bitmask of layers this body tests against. |
| `is_static` | `bool` | `false` | Immovable. Static bodies go in the broadphase but are never swept. |
| `one_way` | `bool` | `false` | Blocks only motion opposing the local +Y axis. |
| `pushable` | `bool` | `false` | Receives the simple impulse response instead of only blocking. |

### `Instance`

An instance of another scene, with sparse property overrides. The source is named by the reserved `scene` key.

No properties beyond the reserved keys.

### `Light2D`

A light contributing to the additive light buffer.

| Property | Type | Default | Notes |
|---|---|---|---|
| `color` | `color` | `"#ffffffff"` | Light colour. |
| `radius` | `scalar` | `64.0` | Falloff radius. |
| `energy` | `scalar` | `1.0` | Brightness multiplier. |
| `shape` | `enum(Radial | Cone)` | `"Radial"` | Radial fills the radius; cone is limited to cone_angle. |
| `cone_angle` | `angle` | — | Cone width, for a cone light. |
| `cast_shadows` | `bool` | `false` | Cast shadows from nearby collider geometry. |

### `Node`

Bare node. Groups children and runs a script; has no presence in the world.

No properties beyond the reserved keys.

### `Node2D`

A node with a transform. The base for anything that exists somewhere.

No properties beyond the reserved keys.

### `Sound`

| Property | Type | Default | Notes |
|---|---|---|---|

## Lua API

Scripts see exactly these globals and nothing else.

| Global | What it gives you |
|---|---|
| `scene` | `find(path)`, `by_id(id)`, `tagged(tag)` |
| `tick` | `count()`, `dt()`, `rate` |
| `rng` | `range(stream, lo, hi)`, `chance(stream, n, d)`, `unit(stream)` |
| `vec2` | `vec2(x, y)`, building a fixed-point vector |
| `fx` | `new`, `parse`, `sin`, `cos`, `from_angle` |
| `log` | `info`, `warn`, `error` |
| `tween` | `to(node, property, target, ticks, easing)`, `cancel(node, property)`, `running(node, property)` |
| `anim` | `play(node, clip)`, `stop(node)`, `frame(node)`, `playing(node)`, `finished(node)` |

A node handle supports `get`, `set`, `find`, `parent`, `children`, `emit`,
`destroy`, `set_velocity`, `velocity`, `world_pos`, `has_tag`, `name`, `path`,
`kind` and `valid`. Indexing a handle reads and writes script variables, except
for `pos`, `rot` and `visible`, which reach the node's transform.

### Tweens and animation

Tweens and animation are simulation state, not presentation. They advance on
ticks, they are snapshotted, and they are in the state hash — a tween outside
the hash could not survive a rollback, and would be left mid-flight writing to
positions that had just been rewound. Easing runs in fixed point for the same
reason everything else does. The easings are `linear`, `ease_in`, `ease_out`
and `ease_in_out`; `pos`, `scale`, `rot` and any scalar, vector, angle or
colour property can be tweened.

Animation clips come from the importer with their frame durations already in
ticks. `on_anim_event(self, name)` fires when playback reaches a frame that
carries an event, which is how a hitbox opens on the swing frame rather than
on a timer someone has to keep in sync by hand.

### The rule that matters

Lua numbers are `f64`. Gameplay arithmetic done in raw Lua numbers and written
into simulation state is the easiest way to break replay. Use `vec2` and `fx`
values, which do their arithmetic in fixed point.

The sandbox has no `os`, `io`, `require`, `dofile`, `load` or `package`, and no
`math.random` — randomness comes from a seeded `rng` stream. `math.sin` and the
other transcendental functions are also absent, because platform maths libraries
do not agree with each other; use `fx.sin` and `fx.cos`, which read committed
lookup tables.
